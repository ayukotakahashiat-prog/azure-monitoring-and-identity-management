# Azure Monitoring and Identity Management

This repository demonstrates hands-on experience configuring monitoring, alerting, and identity management in Microsoft Azure using Azure Monitor and Microsoft Entra ID.

## 🚀 Project Overview
The goal of this project was to simulate real-world cloud administration tasks involving observability, operational monitoring, and user access management. The work focuses on detecting activity, responding to alerts, and managing identities within an Azure environment.

## 🧩 Key Activities
- Reviewed and analyzed Azure activity logs using Azure Monitor
- Created and configured alerts to detect resource activity and changes
- Explored Azure Monitor tools for observability and diagnostics
- Managed users and groups using Microsoft Entra ID
- Applied identity management concepts to control access within Azure

## 🛠️ Technologies Used
- Microsoft Azure
- Azure Monitor
- Azure Alerts
- Microsoft Entra ID (Azure AD)
- Azure Portal

## 🎯 Skills Demonstrated
- Cloud monitoring and observability
- Alert configuration and incident awareness
- Identity and access management fundamentals
- User and group administration
- Operational visibility and governance

## 🔮 Future Improvements
- Implement Log Analytics queries for deeper insights
- Integrate alerts with automation or notification services
